# TheCFO.Site

Fractional finance services for service-based companies generating $2M–$30M in revenue.

## Overview

TheCFO.Site delivers fractional CFO, controllership, and financial leadership services tailored for law firms, PR agencies, marketing firms, and consulting businesses. The site is designed to communicate authority, trust, and modern financial expertise.

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Framer Motion
- React Router v6
- Deployed on Netlify

## Pages

- **Home** — Hero, Stats, Who We Serve, How We Work (5-phase workflow), Testimonials, CTA
- **Services** — Fractional CFO, Controllership, Financial Reporting, FP&A, Strategic Advisory, Cloud Migration
- **Software** — QuickBooks Online, Xero, Dext, Hubdoc, Plooto, Power BI, QuickBooks Time
- **Resources** — Blog, Guides, FAQ
- **About** — Story, Approach, Values, Why Us
- **Careers** — Why Join Us, General Application
- **Contact** — Booking + Contact Form

## Features

- Clean, warm-toned design with navy and golden amber accents
- 5-phase financial infrastructure workflow visualization
- Interactive service cards with hover animations
- Fully responsive (mobile-first)
- SEO optimized

## Development

Built from scratch based on client brand guide and site architecture documentation. All design decisions, color systems, typography, and layout follow the approved brand guidelines.
